The AI-Based Cloud Security Threat Detection System is an intelligent, machine learning-powered web application designed to detect and classify cyber threats in cloud environments by analyzing four key behavioral parameters — failed login attempts, network traffic volume, number of requests, and data transfer size — submitted by the user through a Django-based web interface, where the inputs are preprocessed and normalized before being passed to a trained Random Forest classifier that identifies the activity as either Normal or a specific attack type such as Brute Force, Denial of Service, Port Scan, or Web Attack, after which the result is displayed on an output page along with access to a detailed response module that explains the attack's root cause, potential impact on cloud infrastructure, and recommended prevention and mitigation strategies, making the system not only a powerful threat detection tool but also an educational platform that bridges the gap between artificial intelligence and cybersecurity, built with scalability and extensibility in mind to support future integration with live cloud monitoring systems and continuous learning pipelines, ultimately serving as a practical demonstration of how AI can be leveraged to protect modern cloud environments from increasingly sophisticated cyber threats.
